## Why

The ROADMAP row *"`sync seal`'s memory grows with the claims in the batch"* holds the numbers. Measured on the shipped 0.58.0, `/proc`
sampled:

- **A fixed tree** (the architect's `~/.pgtmp/letters-0.58.0/seal-mem.sh`, built by `s5-build-source.sh`, planeter's edit shape):
  1,000 claims VmData 6 MiB, 10,000 claims 64 MiB. **About 6.5 KB per claim, linear.**
- **A growing tree** (planeter's `~/.pgtmp/letters-0.58.0/planeter-kit/sealmem.sh N grow`, one new path per claim; reproduced by the
  architect):
  - 1,000 claims: 6.8 MiB;
  - 5,000 claims: 59.1 MiB;
  - planeter's 10,000 claims: 181.4 MiB.
  - **More than linear.**
- **Writes grow the same way.** The blob container grew 0.9 → 18.7 MB, consistent with a full path list every 64th block (the checkpoint
  manifests row).
- **The reads are flat per claim** (0.58.0 S).

**A forge seals what a peer sends,** so this memory is peer-driven: the same class as 0.58.0's `sync accept` Security entry. P5 changes
the batch writer, so what the batch holds must be known first.

## M1: attribute it (nothing built)

1. **The build:** a release build of `main` into a fresh target directory, and the probe in a **detached worktree**.
   - **The probe:** F0's counting allocator, `.git-exclude/logs/0.58.0-F0/heapprobe.rs`, with `f0-sites.py` for the site tables, as
     0.58.0 P3a and P4a used it.
   - `unsafe_code` is relaxed there and **never committed.** The worktree and its target are removed after.
   - **Check the primary tree is clean after.**
2. **The shapes**, each on tmpfs, inside an R1 scope:
   - **the fixed tree:** 1,000 and 10,000 claims (`s5-build-source.sh`'s planeter shape; `seal-mem.sh` drives it);
   - **the growing tree:** 1,000, 3,000, 5,000 and 10,000 claims (`sealmem.sh N grow`);
   - **into the current branch** (the worktree written) **and into another branch**, at 10,000 in each shape.
   - **Copy the scripts into `.git-exclude/logs/0.59.0-M1/`** and run them from there. Keep every output.
3. **The baseline:** one shape at one size also on the shipped 0.58.0 (`~/.pgtmp/rel-0.58.0/x/prikk`). State whether `main` moved since
   (K changed writers, not the batch).
4. **Attribute:**
   - the heap at the peak by site;
   - what is still held at the end, against what is transient;
   - **what grows with the claims**, and **what grows with claims × paths** (the growing tree);
   - what each site holds per claim, in bytes, at two sizes, so the slope is measured and not inferred.
   - Name the structures (the type and the field) and the line that allocates them.
5. **The answer, per growing site, exactly one of:**
   - **(a) state the batch needs,** with what bounds it and the sentence the docs should carry; or
   - **(b) state it does not need,** which P5 drops. Say what dropping it changes, but build nothing.
6. **The extrapolation, labelled as an extrapolation:**
   - one artifact at the default 256 MiB bound holds about 360,000 claims in this shape;
   - give its memory from the measured slopes in both shapes (the row's estimate is 2.2 GB at 6.5 KB per claim, and 6.2 GB at 18 KB);
   - **say whether a bound is needed** (a refusal above N claims, or a streamed batch). That is a design question for P5, and nothing is
     built here.
7. **Splitting a batch:**
   - **Can a user split one correctly, and how?** The claims file is in claim-id order, not chain order, so a split by lines is refused
     (measured 2026-11-21, `planeter-kit/sealmem-split.sh`).
   - Answer from the code: what order would split, whether any command produces it, and what the refusal says today.
   - **No interim advice is offered** until it is measured.
8. **A control that can fail:** a perturbation in the probe worktree that keeps one extra allocation per claim (a `Vec` that is never
   freed) must appear as its own site, with the slope it was given. Without it, an attribution that finds nothing proves nothing.
9. **The rules as in step 0:**
   - an R1 scope for every run, and `date` at the start and the end;
   - the outputs cited;
   - **no commit is expected.** If the docs gain the bound's sentence, that is P5's.
   - **Stop at the report.**
