## H1: what is true today, measured (nothing designed)

1. **Key custody:**
   - where `setup` puts each seed, and what each command reads (author, maintainer, both, neither), for every command that signs or
     verifies. **This is a table from the code, and each row is checked on the binary.**
   - **Can an author-only setup exist today?** Set one up (no maintainer seed anywhere prikk looks) and run every command an author needs.
     **Say which refuse, and with what.**
2. **Delivering an author's work:**
   - today only a sealed block under the author repository's own key, which the receiver re-seals;
   - **measure `sync build` → `sync accept` → `sync seal` with the author holding no maintainer seed;**
   - **is a queue of unsealed patches deliverable?** Say what exists, and where it stops.
3. **Trust transitions:**
   - **what `trust maintainer add` and `remove` write** (signed or not, by whom);
   - **what a copy can check** (does `verify` on a copy see that a key was added by an adopted maintainer?);
   - **what removal does to history** (planeter's measurement, reproduced).
4. **Least privilege, command by command:**
   - which commands need a seed only to plan (`ref complete --plan-only`, the repair verbs' `--plan-only`, `doctor`), and why;
   - **a plan that signs nothing should need no seed.** Where it does, find out why.
5. **The report:** the tables, each fact with the command that showed it. **No design.**
