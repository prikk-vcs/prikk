## 3a — one classifier; `bundle import` refuses a non-fast-forward

- **Factor the classifier out of `preview_impact`** (`bundle/preview.rs:252-330`), so that it returns the class and
  nothing more. `bundle preview` calls it, and so does every importer in 3c.
- **The classes:** `already-included` splits into `already-at-tip` and `rollback`.
  - **`bundle preview` has shipped `already-included`, and planeter reads it.** Keep the existing field and its values
    unchanged, and add a `class` field with the six classes. The change is additive, so nothing a script reads today
    changes. Say so in the CHANGELOG and in the planeter letter.
- **`ref_state_chain`** (`extends`, `older`, `unrelated`), against the pointer being replaced.
- **In `import_bundle`:**
  - read the current received pointer with `read_received_pointer`, after pass 1 and before the first write, under the
    locks already held (`bundle.rs:1859`);
  - refuse `rollback`, `diverged` and `does-not-connect` when a pointer exists, unless `--allow-non-fast-forward` is
    given;
  - **`already-at-tip` with `older` writes nothing** and exits 0.
- **Tests:** every class × pointer absent or present, with and without the flag, plus `already-at-tip` + `older`.
  Reuse 2A's fixture: block1, then block1b.
- **Red controls:**
  - the classifier forced to `fast-forward`: the refusal tests fail;
  - the read moved before the lock: show that a test fails, or say why none can, and add one that does.
- **Text:** `commands.md` (`bundle import`, `bundle preview`) and the CHANGELOG.

## 3d — a path outside this version's rule is not damage

- **Measured on 0.55.0 (2C v2 §R7):** `verify` ("integrity error … does not decode"), `doctor` ("preserve the
  repository and inspect"), and `show` ("malformed") on a patch whose path a newer rule would allow.
- **The fix:**
  - a path refused **by the path rule** at decode gets its own error classification, kept distinct from damage;
  - every reader names it in one sentence: this path is outside what this version of prikk accepts, and a newer
    version of prikk may have written it;
  - `verify` and `doctor` report it as that, not as a failed object needing repair;
  - **every command still refuses.**
- **Tests:** reuse 2C v2's perturbed-build fixture approach in a test (encode a patch past the validator). Cover
  `verify`, `doctor`, `show`, `tree`, `extract` and `commit`.
- **Red control:** the classification removed: the "damage" wording returns.

## 3e — the claim walk, and `extract --claim` over a chain

- **One walk** (D4):
  - one map from block id to claims, built in one scan;
  - from the named claim back to a parent that is a **reachable** block (`block_is_sealed_or_received`);
  - a reachable block wins over a claim recognizing it.
- **What the walk records:** each link's signature outcome, and its structural failures:
  - `claim-chain-shared-block` (D1, including the exception for exactly one `sound` candidate);
  - `claim-chain-cycle`;
  - `claim-has-several-parents` at any link;
  - `claim-parent-not-sealed`.
- **Signatures (D2):**
  - `invalid` at any link, **the named claim included**, refuses `claim-signature-invalid`;
  - `unverifiable` proceeds.
- **Fold:** a link that does not fold refuses `claim-does-not-fold`, never `damaged-repository`.
- **Bound (D3):** the anchor's distance plus the chain's hops is checked against `MAX_ANCHOR_DISTANCE`, refusing
  `no-checkpoint-in-reach` and naming both numbers; `--allow-full-replay` overrides it.
- **`extract-report-v1`, additively:**
  - `chain[]`, root to foot, each entry `{claim_id, target_block_id, parent_block_ids, signature}`;
  - `chain_signature`, the weakest outcome;
  - the text form names each link, and prints "unverified" when the weakest is `unverifiable`.
- **Tests:** every row of 2B's case table, with hand-made claims for shared-block, cycle, merge mid-chain, invalid,
  unsigned, fold failure, and the bound. **Include the single-claim output changes:**
  - a forged claim refuses;
  - a held but unreached parent refuses;
  - a fold failure is classified.
- **Red controls:**
  - the signature check removed;
  - reachability replaced by existence;
  - the hop count left out of the bound.
